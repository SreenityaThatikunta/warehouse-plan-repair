# Design Decisions

| # | Decision | Rationale |
|---|---|---|
| D1 | Initial MAPF uses **prioritized planning with Space-Time A\*** and a reservation table. The longest task chain goes first, with random restarts on failure | Recommended by the assignment. It is fast and scales to 50+ agents. Reservations can be edited per agent, which is what local repair needs. |
| D2 | Multi-goal ST-A* with state `(x, y, goal_idx, t)`. The heuristic is the exact static distance through the remaining goals | Plans an agent's whole pickup→delivery→…→home chain in one search, with no gluing of separate segments. |
| D3 | Repair is **tiered**: solo replan → negotiate with the smallest set of neighbours that block the agent, growing the set → the same with radius 2R → hold and retry | Tries the options that change the fewest agents first, which directly serves the goal of "minimise the number of agents altered". |
| D4 | The global planner is never called during local repair. Full replan exists only as a **baseline** | The assignment says repair must not start from scratch. The baseline measures what staying local costs. |
| D5 | "Agents altered" means the future path after repair differs from the path just before the disruption. Cascades count toward the triggering disruption. We also report `direct` (robots whose plan the event itself invalidated) and `collateral` (= altered − direct) | Gives each disruption a clear count that can be measured, and separates unavoidable changes from those the repair caused. |
| D6 | Emergency agents get top priority in negotiation (they plan first) and negotiate for any detour (δ = 0). Other robots can't make an emergency robot move | Emergency tasks are high priority by definition. |
| D7 | Permanent breakdown: the broken robot's unfinished tasks are auctioned to robots within radius R, doubling R if nobody is in range. The lowest marginal cost wins. A carried item is handed off at a reachable free cell next to the broken robot | Only the winning robot's plan changes. The auction is a standard decentralised allocation method. |
| D8 | **Tier 0 (a separate wait-only check) was dropped.** Solo ST-A* already considers waiting and returns the best wait-or-detour plan | It adds nothing to cost or to the number of altered agents. |
| D9 | Accepting a negotiation: a coalition S is accepted only if `extra delay of S and the agent + λ·|S| < solo detour delay`. Defaults: λ = 3, δ = 4, R = 6, at most 3 coalition members, and only robots that block the agent's ideal path are candidates. The smallest size that works wins | Balances fewer altered agents against total time. λ sets the price of changing one more robot's plan. |
| D10 | Robots **return to their dock** after their last task. Docks are **dead-end bays** (no sideways moves between docks) | Robots must park somewhere. Parking at stations or in aisles blocks others, and when docks formed a through-row, robots drove through other robots' docks, which forced long waits before those robots could park. |
| D11 | Main metric SoC = Σ over robots of the time of the last delivery. Makespan = the latest delivery. Travel back to the dock is excluded, but reported separately as `soc_total` | "Time to accomplish their tasks". |
| D12 | ST-A* uses a lower bound on the earliest time the robot can park at its final goal (after every other reservation of that cell), plus a fast reachability check for impossible cases | Without these, searches flooded huge plateaus of states when the goal cell was still in use by others, which made full replanning fail or take seconds. |
| D13 | Robots learn a blockage's duration when it occurs, for example from a maintenance estimate. Future disruptions are never known in advance | Realistic, and repair needs an end time for temporary obstacles. |
| D14 | Hold (Tier 4) = the robot stays on its cell with a "parked" reservation and retries every step. On retry, **negotiation is allowed under every strategy** | Two robots on hold can block each other forever (seen in 1-wide aisles). Only a joint replan breaks that deadlock. |
| D15 | Full-replan baseline: all live robots are re-planned with prioritized ST-A* from the current state (emergency and broken robots first), with up to 5 random restarts. If that fails, it falls back to local repair | Gives an honest comparison: the best the global planner can do at that moment, and how many robots it changes. |
| D16 | Blockages avoid docks, stations, occupied cells and cells that are still some robot's goal. Permanent ones also must not disconnect the map. Emergency cells are checked for reachability when the event fires | Keeps every task solvable, so failures come from repair rather than from impossible instances. |
